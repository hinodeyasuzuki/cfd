室内空気の流れシミュレーションを行うため、3Dフィールドにボクセルを配置設定をするツールをjavascirptで作成する。

出力は、3次元配列 meshtype[x][y][z]とし、X（横）、Y（高さ）、Z（奥行）方向とする。
フィールドのメッシュ数は nMeshX,nMeshY,nMeshZ
1メッシュあたりの実際の長さは unitSize(m）とする

ボクセルの種類は以下のとおりとする
      INSIDE : 1,		//室内空気
      BOTTOM : 2,		//床
      TOP : 3,		  //天井
      WINDOW : 4,		//窓
      OUTSIDE : 5,	//外壁
      SIDE : 6,		  //屋内壁
      OBSTACLE : 7,	//障害物
      AC : 8,			  //エアコン（下面から送風、上面から吸収）
      CL : 9,			  //サーキュレータ（Xプラスから吸収、上面Yから送風）

初期画面でメッシュ数を指定し、
初期状態ではフィールドの側面は全て OUTSIDE、上面は　TOP、下面はBOTTOM、内側はINSIDEとする。
3D視点移動ができるようにし、操作パネルからボクセルの種類を選んで、立体てきな位置を指定してボクセルを設置する。
このとき、手前面となる壁や天井などは表示しない。INSIDEも表示しない。
